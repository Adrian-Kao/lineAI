萬春宮 DEMO：環境需求與組員安裝指令
更新日期：2026-09-18

一、必要環境
Node.js 24.x（已驗證 24.18.0）
npm 11.x（已驗證 11.16.0）
Git
不需要 Python、pip、Docker、pnpm 或 LINE CLI。
本檔是安裝說明；npm 的依賴清單為 my-react-app/package.json，
確切版本為 my-react-app/package-lock.json，由 npm ci 一次安裝。

二、首次取得專案（未下載專案的人執行）
git clone https://github.com/Adrian-Kao/lineAI.git
cd lineAI

三、安裝與啟動（從專案根目錄執行，Windows PowerShell）
node --version
npm --version
cd my-react-app
npm ci
if (-not (Test-Path .env.local)) { Copy-Item .env.example .env.local }
npm run dev

macOS / Linux 建立設定檔改用：
cp -n .env.example .env.local
其餘 npm 指令相同。

四、已安裝套件版本（其他組員不必逐一安裝，執行 npm ci 即可）
react 19.3.0
react-dom 19.3.0
react-router 8.4.0
@line/liff 2.31.0
vite 8.3.0
@vitejs/plugin-react 6.1.1
eslint 10.10.0
@eslint/js 10.0.1
eslint-plugin-react-hooks 7.1.1
eslint-plugin-react-refresh 0.5.7
globals 17.12.0
@types/react 19.3.0
@types/react-dom 19.3.0
Context、Canvas、IndexedDB 不需另裝套件。

五、手動設定
編輯 my-react-app/.env.local：
VITE_LIFF_ID=團隊在LINE Developers Console取得的LIFF_ID
VITE_AUTH_MODE=line
修改後重啟 npm run dev。
.env.local 不提交 Git；VITE_* 是公開資訊，不可放私密憑證。
LINE SDK 已安裝，但登入和遊戲功能目前仍是程式骨架。
LIFF_ID 無法透過 npm 安裝取得，需由團隊設定 channel 並提供。

六、開發檢查（在 my-react-app 目錄執行）
npm run lint
npm run build
npm run preview
本次 lint、build 與開發伺服器已驗證成功；尚未驗證 LINE 實機功能。

七、未安裝 Node.js 的 Windows 電腦
winget install --id OpenJS.NodeJS.LTS --exact
安裝後重開終端機，再確認 node --version 與 npm --version。
LTS 版本會變動，本專案要求 Node.js 24.x。
若 LTS 已非 24.x，請從 https://nodejs.org/en/download 取得 24.x。

八、可選 Vercel CLI
使用 Vercel 網頁連 GitHub 不需要 CLI。
需要 CLI 才執行：
npm install --global vercel
vercel login
Vercel 專案設定：Root Directory=my-react-app，
Build Command=npm run build，Output Directory=dist。
LINE endpoint 與 Vercel 環境變數另由帳號負責人設定。

九、團隊版本控制
提交 package.json、package-lock.json、.env.example 與程式碼。
不提交 node_modules、dist、.npm-cache 或 .env.local。
其他組員必須先取得包含最新 package-lock.json 的專案版本。
